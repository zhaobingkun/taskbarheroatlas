Chest cooldown vs personal timer

Searches for Task Bar Hero chest cooldown, TBH chest timer and chest tracker often mix two different needs. A cooldown is a game-data claim. A timer is a reminder you set for your own routine. Atlas only provides the reminder unless a current official source confirms a schedule.

When to use this tracker

Repeat sessionsKeep a visible reminder while testing a farming loop.
Chest observationsPair the timer with a source and attempt log.
Drop notesUse it beside drop-rate records, not as proof of a rate.
Patch checksRe-check assumptions after updates.

What this tool does not claim

  • It does not confirm 30 or 60 minutes as official chest cooldowns.
  • It does not keep running after you close the tab.
  • It does not inspect your Steam account or game state.
  • It does not replace a drop-rate sample log.

Chest Timer FAQ

Is this an official Task Bar Hero chest cooldown?

No. It is a local timer. The preset buttons are convenient reminder intervals, not verified game data.

Does the timer keep running after I close the tab?

No. This first release is intentionally a lightweight in-tab timer.

How should I track chest drops?

Use the drop-rate page and chest drop notes to record source, attempts, rewards, patch and observation status.
