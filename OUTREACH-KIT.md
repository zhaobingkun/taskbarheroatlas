# Task Bar Hero Atlas: Community Outreach Kit

Prepared: 2026-07-22

## Purpose and guardrails

This is a community-sharing kit for `taskbarheroatlas.com`, not a link-buying or mass-posting plan.

- Disclose that the site is independently made and not affiliated with Nugem Studio or Tesseract Studio.
- Link only where the page directly answers the conversation. One useful link is enough.
- Do not claim official chest cooldowns, drop rates, codes, live prices, or a universal best build unless the page has versioned evidence.
- Read each community's current rules before posting. If self-promotion is not allowed, answer without a link and ask a moderator before sharing a resource.
- Never use paid link packages, copy the same post across communities, ask for exact-match anchor text, or offer compensation for a link.

## Recommended release sequence

1. Post the Chest Timer in **one** community first. Use the relevant tracking link and monitor replies for 48 hours.
2. Reply to genuine questions about reminders, chest tracking, or browser tools. Do not add the link to unrelated discussions.
3. Publish the Rune checklist as a separate, useful resource three to five days later, in a different community or when a matching question appears.
4. Review GA4 acquisition after seven days. Keep the community/page pair that sends engaged visitors; stop using placements with no clicks or negative feedback.

Do not publish the same copy in multiple communities on the same day.

## Before each post

- Read the current rules and recent pinned posts.
- Use one asset and one tracking link.
- Make the post useful without requiring the click.
- Add the independent-site disclosure.
- Proofread game facts and remove anything that is not sourced.
- Check replies once or twice, answer genuinely, then stop rather than bumping the post.
