Rune guide or Rune Tree?

/runes/ is the Task Bar Hero Runes guide hub: it explains rune jobs, evidence labels and which child page to open. /rune-tree/ is the TBH Rune Tree route page: it handles rune map, full rune tree, rune planner and route-record searches. Keeping the intent split prevents the two pages from competing for the same query.

Four-step rune test

  1. Name the wall. Decide whether the problem is speed, single-target damage or survival.
  2. Pick one fixed target. Use the same route and conditions for comparison.
  3. Change one rune decision. Avoid moving gear, class and runes at the same time.
  4. Keep the result with the patch. Mark every note with v1.01.05 or the current patch used.

Rune FAQ

What are the best Task Bar Hero runes?

The best rune choice depends on the current bottleneck. Use clear-speed runes for repeated farms, boss-damage runes for hard targets and survival runes when runs end too early.

Where is the full Rune Tree?

Use the TBH Rune Tree page for rune map, full rune tree, rune planner and route-record guidance.

Why are rune numbers limited?

Atlas only publishes a number when it has a current source or repeatable test record. This avoids turning old or copied rune lists into false database data.
