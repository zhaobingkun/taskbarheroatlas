How to use the Rune Tree planner

  1. Pick the route goal. Clear speed, boss damage, survival, or resource routing.
  2. Write the baseline. Patch, stage, difficulty, class/build assumptions and current failure point.
  3. Mark candidate nodes. Only mark nodes that logically address the goal.
  4. Move one decision at a time. Do not change route, build and gear together.
  5. Record the result. Keep clear time, completion rate or failure point with the route.

When to change your Rune Tree route

Change the route after a patch, a meaningful gear shift, a new stage wall, or repeated evidence that the old route solved the previous problem. Do not reset just because a copied screenshot claims a universal best path without version and target context.

Rune Tree FAQ

Is there one best TBH Rune Tree route?

No. The best route depends on the current wall and patch. A route that improves farming speed may be wrong for boss damage or survival.

Is the full TBH Rune Tree map available?

Not as a current official node-value table. Atlas shows the map status and a usable route record, but will only publish exact values when current source or repeatable evidence is available.

What does the Rune Tree planner record?

Record the patch, target stage, difficulty, class or build assumptions, route change and repeatable result. This keeps a route useful even when the official node values are not published.

How is this different from the Runes page?

The Runes page chooses the job. This Rune Tree page turns that job into a route planner and record template.
