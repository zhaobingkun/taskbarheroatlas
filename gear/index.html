GEAR REFERENCE / CHECKED OCT 22, 2026

Task Bar Hero gear: upgrade the problem, not the item color.

Gear matters when it moves the next result: a cleaner farm, a passed boss check, or a stable stage. The official v1.02.00 release confirms that Level 90 gear, accessories and new Unique Stats are live in Plaguelands; exact build value and route rankings still need current testing.

Ver 1.3.0: Relics and regular Synthesis

Clearing Plaguelands once unlocks the Relic UI. Reliquary inherent stats affect the party; Uncommon and higher Reliquaries have colored slots for matching Relics, while White Relics fit any color. Contaminated items come from Plaguelands or Contaminated Act Boss chests with unspecified chances. Read Offering and Attunement basics before comparing upgrades.

For regular gear/material Synthesis, Immortal → Arcana success changes from 49.9% to 80%, and Arcana → Beyond from 33.28% to 50%; a Fixed Level option is added. These are not Relic Synthesis probabilities. Material Stash is paid DLC with dedicated material slots capped at 999 per material, not a free universal inventory expansion.

Source: official Ver 1.3.0 announcement, October 21; checked October 22, 2026. Recommendations still require current repeatable testing.

QUICK ANSWER

Keep an upgrade when it improves a measured outcome on the same route. The current released baseline tracked is Ver 1.3.0. Level 90 items and new Unique Stats are live, but a useful upgrade recommendation still needs a stated source, role and repeatable result.

Evaluate an item in context

  1. Name the stage or activity it should improve.
  2. Test before and after with the same build conditions.
  3. Check whether the new effect changes Rune or skill priorities.
  4. Record the game version and item state alongside the result.

Live Plaguelands gear context

The Sep 7 official release lists Level 90 gear and accessories, Type C market status, Level 90 stage sources, Level 80-90 synthesis recipes and Level 90 crafting recipes. It also lists new Unique Stats and their item effects; use the release guide for the full evidence boundary rather than treating item level alone as a ranking.
