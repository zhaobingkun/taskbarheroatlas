BUILD RULE

For v1.01.02, do not copy a Task Bar Hero build unless it names the job, patch, target activity, core assumptions and repeatable result. A farming build, boss build and survival build can make opposite trade-offs.

How to test a Task Bar Hero build

  1. Name the target. Use one stage, boss, route or farming loop.
  2. Record the patch. This page currently tracks v1.01.02.
  3. Lock the baseline. Keep class, gear assumptions and Rune goal visible.
  4. Change one meaningful input. Avoid replacing the whole setup before you know what worked.
  5. Repeat the result. Keep a build only when the result appears more than once.

Build FAQ

What is the best Task Bar Hero build?

There is no responsible universal answer without the patch, activity and bottleneck. For v1.01.02, start by deciding whether you need farming speed, boss reliability or survival stability.

Why does this page avoid a fixed tier list?

A fixed list can become wrong after a patch, gear change or different stage condition. The build hub keeps the test method visible so later named routes can be verified.

Where should a beginner start?

Use the beginner build route first, then move to Rune, farming and drop pages once you know the specific wall.
