Plaguelands release status

The official v1.02.00 release opens Plaguelands through the Portal UI after the stated difficulty and Stage 1-10 requirements. The Sep 8 known-issues notice listed a progress-reset condition alongside UI, translation and Sanctuary problems; v1.02.01 later records fixes for the reset and several of those specific issues. v1.02.02 adds three fixes for DLC chest contents, Slayer Axe Spin cooldowns and formation access. v1.02.03 added Plaguelands chest-drop Rune nodes and selected minimum timings. Ver 1.2.4 later fixed the reported chest waiting-time resets after stage changes and relaunches, and removed fixed minimum waits between chest acquisitions.

Stage test checklist

  1. Write the Act, difficulty and stage you are testing.
  2. Classify the failure: wave time, a boss, or survival.
  3. Change one relevant input, then repeat the same target.
  4. Keep the route only if its result is repeatable on the current patch, Ver 1.2.4.
