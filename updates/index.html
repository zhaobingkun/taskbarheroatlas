Task Bar Hero v1.01.05 patch notes: what changed?

The official Aug 11 announcement updates the game to v1.01.05. The newer Aug 19 dev note previews the planned Plaguelands update, but does not announce a new live version. This desk keeps released fixes and in-development features separate.

CURRENT OFFICIAL PATCH

v1.01.05 is the current released patch tracked by Atlas. The latest official feed entry is an Aug 19 development note, not a version update; its planned September features remain in development. This page was checked on August 21, 2026.

What the Aug 19 Plaguelands dev note confirms

The official development note previews four planned features: the Plaguelands stage type, level 90 items with about 20 kinds of new Unique Stats, new Rune types plus additions to existing types, and a Skin System. It says the content is being prepared for early September and warns that the final version may differ.

What players should do after the v1.01.05 update

  1. Confirm the in-game version. Use v1.01.05 before comparing a route or reporting a result.
  2. Update before opening chests or claiming important mail. The official note specifically includes a chest crash and a mailbox item-delivery issue on certain accounts.
  3. Keep save evidence intact. The announcement says backups are created every 24 hours and retained for up to 30 days; it does not state a manual restore workflow.
  4. Re-test affected guidance. A bug fix is not automatically a balance proof; update a build, market note or route only after the relevant behavior is checked.
