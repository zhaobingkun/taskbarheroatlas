DROP NOTES / CHESTS

Task Bar Hero chests: source and timing need context.

A chest result is only useful evidence when its source, event conditions, version and observation count are visible alongside it.

DATA BOUNDARY

This page does not claim a universal chest schedule or reward table. Ver 1.2.8 removed fixed minimum waits between chest acquisitions and uses a total-per-period limit whose numeric value is not published. It is the child page for verified source notes and clearly labeled observations.

Record a chest observation properly

  • Name the chest or source exactly.
  • Include the active version and any event condition.
  • Count attempts, not only desirable rewards.
  • Mark the result observed until current evidence supports it.

Observation log

For each chest record, keep the exact source, difficulty, stage, chest type, patch, time since the previous acquisition, whether the stage changed, and the number of attempts. Mark an observation as player-tested until a current official source supports a broader rule. This makes the page useful without turning a small sample into a fake drop percentage.
