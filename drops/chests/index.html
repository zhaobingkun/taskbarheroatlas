DROP NOTES / CHESTS

Task Bar Hero chests: source and timing need context.

A chest result is only useful evidence when its source, event conditions, version and observation count are visible alongside it.

Ver 1.3.0: separate the chest contexts

Use the Plaguelands timing and relative-drop table for its difficulty-specific changes. Halloween chests are separate: up to 10 regular chests per entry and one boss chest for defeating the boss, storage caps of 40 each, and no Rune effects. Do not combine these samples with normal or Plaguelands chests.

Source: official Ver 1.3.0 announcement, October 21; content facts checked October 22, 2026. Client hotfixes through Ver 1.3.2 were checked October 28, 2026. They leave these facts in place and do not add absolute drop rates or a best route. See the Ver 1.3.2 patch desk. Recommendations still require current repeatable testing.

DATA BOUNDARY

This page does not claim a universal chest schedule or reward table. The historical Ver 1.2.4 note removed fixed minimum waits and described a total-per-period limit without a numeric value. Ver 1.3.0 publishes the content-baseline region-specific timing changes and relative chest boosts; the official client is through Ver 1.3.2. Neither note gives a complete absolute reward table. Ver 1.3.2 only adds that Halloween dungeon tickets drop for the matching difficulty, with the previous lower-tier ticket chance added to that difficulty. It is the child page for verified source notes and clearly labeled observations.

Record a chest observation properly

  • Name the chest or source exactly.
  • Include the active version and any event condition.
  • Count attempts, not only desirable rewards.
  • Mark the result observed until current evidence supports it.

Observation log

For each chest record, keep the exact source, difficulty, stage, chest type, patch, time since the previous acquisition, whether the stage changed, and the number of attempts. Mark an observation as player-tested until a current official source supports a broader rule. This makes the page useful without turning a small sample into a fake drop percentage.
