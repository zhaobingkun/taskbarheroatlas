Chest drops: what to record

Searches like Task Bar Hero chest drop rate, TBH chest drop rate and Task Bar Hero chest cooldown all need the same context. A useful chest note shows the chest source, the active patch, the timing method, the number of attempts, and every reward category observed.

SourceName the chest, stage, event, or route that produced it.
AttemptsCount every open or run, not only the desirable rewards.
ConditionsKeep difficulty, event state and account assumptions separate.
VersionMark the observation with v1.01.05 or the active patch used.

Gear drops and stage drops

For gear and stage rewards, the useful question is not only “what dropped?” but “what route produced it under repeatable conditions?” Keep a separate line for stage, difficulty, clear time, item rarity, item slot and whether the run was stable. If the route changes, start a new sample rather than merging incompatible data.

How many samples are enough?

A tiny sample can point to a lead, but it cannot prove a precise rate. Use 10-20 attempts only as an early check, 50+ attempts as a useful route note, and much larger samples before presenting a percentage with confidence. Even then, keep the label as observed unless an official source confirms it.

Drop Rates FAQ

Are Task Bar Hero drop rates official on this page?

No. Values are official only when this page shows a current official source. The current v1.01.05 desk does not publish invented numeric rates.

What is the difference between drop rate and drop source?

A drop source tells you where an item or reward may come from. A drop rate claims how often it appears. Sources are easier to document; rates require many clean attempts or official data.

Where should I track chest drops?

Use the chest child page for chest-specific notes, and use the timer only as a personal reminder. The timer is not an official cooldown table.
